## Context

The `Company` model is implemented and migrated (from the archived `add-sales-contract-schema`
change), but there is no UI to manage companies. chuquan is still a near-bare scaffold:
the only route is `app/routes/_index.tsx`, there is no `_auth` layout, `app/auth/` is empty,
and `app/sessions.server.tsx` exposes only cookie `sessionStorage` (`getSession` /
`commitSession` / `destroySession`) — explicitly "a minimal base to build real auth on top
of." There is no login flow or token verification yet, and no existing CrudTable wiring.

So this change does two things: it delivers the Companies page **and** stands up chuquan's
first reusable route → service → table-config pattern. The stack is already installed —
`@aic-kits/react` (`Table`, form controls, theming), `@aic-kits/remix` (`useCrudTable`,
`handleCrudRouteAction`), Prisma singleton (`~/lib/prisma`), styled-components, Remix v2 —
so the approach mirrors the proven opilot-pm pattern and the conventions in `project.md`.

## Goals / Non-Goals

**Goals:**
- A Companies management page: paginated/searchable/sortable list + add + edit + delete,
  built on the `@aic-kits` CrudTable stack (no bespoke table component).
- Establish the reusable, copyable pattern for chuquan CRUD pages: a `*.service.ts` class,
  a per-model `CrudActionConfig`, column builders, and a route `loader`/`action`.
- Surface friendly errors (duplicate tax code, delete-while-referenced).

**Non-Goals:**
- Authentication / auth-gating the page. chuquan has no login flow yet (only session
  storage), so the Companies page is **open for now**; gating is a follow-up once auth
  exists. (No `requireUserId`, no `_auth` layout in this change.)
- Contract UI and selecting companies as contract parties (separate change).
- Any schema change (`Company` already exists).

## Decisions

### 1. Use the `@aic-kits` CRUD stack end-to-end

Route `action` delegates to `handleCrudRouteAction(request, getCompanyCrudConfig(prisma))`;
the component calls `useCrudTable(...)` and spreads the result into `@aic-kits/react`'s
`Table`. The `loader` lists via `parseTableParams(...)` + `CompanyService.getPaginatedCompanies`.
This is opilot-pm's proven happy path and what `project.md` endorses, so we do not build a
custom table.

### 2. Service does the read; writes are declarative via `createCrudModel`

This is the actual opilot-pm split (`_auth.ai-aff.products`): the per-entity service exposes
**only the paginated read** — `CompanyService.getAll(params)` — which builds a `where`
(search `OR` on `name` / `taxCode`, `mode: 'insensitive'`), a whitelisted `orderBy`, runs
`findMany({ skip, take })` + `count` in parallel, and maps Prisma rows to a flat `CompanyRow`
DTO. It imports the **`prisma` singleton** (`~/lib/prisma`), never a local client.
Create / update / delete are **not** hand-written — they are generated by a reusable
`createCrudModel({ model: prisma.company, fields, mapResponse })` helper used
in the CRUD config, so write logic stays declarative. DTO/param/result types live in
`app/models/company.model.ts` (`CompanyRow`, `CompanyListParams`, `CompanyListResult`); the
generic `Column` / `RecordWithId` / `PaginationParams` types come straight from
`@aic-kits/react`. Full code in the Example implementation below.

### 3. Delete guard via FK `RESTRICT` — error mapping handled by `handleCrudRouteAction`

The `Contract → Company` FKs are `ON DELETE RESTRICT`, so deleting a referenced company
fails at the DB with Prisma `P2003`. `createCrudModel` deliberately does **not** catch it:
swallowing the *coded* error and re-throwing a plain `Error` makes `handleCrudRouteAction`
return a **500** (it only friendly-maps Prisma errors that still carry a `.code`). Instead the
coded error propagates and the library maps it to a clean **400 "Referenced record does not
exist"** — verified at runtime. Likewise `P2002` → **409 "already exists"** (duplicate
`taxCode`) and `P2025` → 404, all handled by the library for free. The `getAll` DTO carries
`contractCount` (`_count` of buyer + seller contracts) so the table can additionally
hint/disable the delete affordance. *Note: the library's P2003 wording is generic; a clearer
per-entity message would need a UI pre-check on `contractCount`, since the `validate` hook is
synchronous (`l(e, r)`, not awaited) and cannot do a DB lookup.*

### 4. The files this establishes (chuquan's first CRUD page + reusable helpers)

- `app/routes/companies.tsx` — the page: `loader` (`handleData` + service), `action`
  (one-line `handleCrudRouteAction`), component (`useCrudTable` → `<Table>`). Open for now
  (no auth gate); move under an `_auth` layout when login lands.
- `app/config/company-table.ts` — `COMPANY_TABLE` (URL-param names, defaults, `requiredFields`).
- `app/config/company-table.server.ts` — `getCompanyCrudConfig(prisma)` (the `createCrudModel`).
- `app/components/company/columns.tsx` — `buildCompanyColumns()` (columns double as add/edit
  form fields via `editable` / `type` / `required`).
- `app/services/company.service.ts` — `CompanyService.getAll`.
- `app/utils/handle-data.server.ts` + `app/utils/crud-model.server.ts` — the two reusable
  helpers copied from opilot-pm (loader param-parsing + declarative write model); later CRUD
  pages reuse both.

## Risks / Trade-offs

- **No auth yet.** The Companies page is open in this change (no login flow exists). When
  auth is built, move the route under an `_auth` layout and add the gate then.
- **First-of-pattern cost.** This change also stands up the table-config shape and the
  column-builder convention — more boilerplate than later CRUD pages, which will copy this
  one. Accepted: it pays off on the next entity (e.g. contracts).
- **`@aic-kits` version drift.** chuquan is on `0.39.1` vs opilot-pm's `0.40.0`. The
  `useCrudTable` / `handleCrudRouteAction` / `Table` surface should match, but exact export
  names and option shapes must be verified against chuquan's installed `@aic-kits/remix`
  during implementation rather than assumed from opilot-pm.
- **Copied helpers.** `createCrudModel` and `handleData` are lifted near-verbatim from
  opilot-pm onto `@aic-kits` primitives. Keep them generic (no Company specifics) so later
  entities (contracts, etc.) reuse them rather than forking.

### `app/services/company.service.ts` — the paginated read only

```ts
import { Prisma } from '@prisma/client';
import { prisma } from '~/lib/prisma';
import type {
  CompanyListParams,
  CompanyListResult,
  CompanyRow,
} from '~/models/company.model';

const SORTABLE = new Set(['name', 'taxCode', 'createdAt']);

export class CompanyService {
  static async getAll(params: CompanyListParams): Promise<CompanyListResult> {
    const { page, pageSize, sortBy, sortDirection, search } = params;

    const where: Prisma.CompanyWhereInput = search
      ? {
          OR: [
            { name: { contains: search, mode: 'insensitive' } },
            { taxCode: { contains: search, mode: 'insensitive' } },
          ],
        }
      : {};

    const orderBy: Prisma.CompanyOrderByWithRelationInput = SORTABLE.has(sortBy)
      ? { [sortBy]: sortDirection }
      : { name: 'asc' };

    const [rows, total] = await Promise.all([
      prisma.company.findMany({
        where,
        orderBy,
        skip: (page - 1) * pageSize,
        take: pageSize,
        include: {
          _count: { select: { buyerContracts: true, sellerContracts: true } },
        },
      }),
      prisma.company.count({ where }),
    ]);

    const data: CompanyRow[] = rows.map((c) => ({
      id: c.id,
      name: c.name,
      taxCode: c.taxCode,
      address: c.address,
      phone: c.phone,
      bankAccount: c.bankAccount,
      contractCount: c._count.buyerContracts + c._count.sellerContracts,
      createdAt: c.createdAt,
      updatedAt: c.updatedAt,
    }));

    return { data, total, page, pageSize };
  }
}
```

### `app/utils/crud-model.server.ts` — reusable (copied from opilot-pm)

Generates `create` / `update` / `delete` from a declarative field spec; translates the FK
error on delete.

```ts
import type { PrismaModelDelegate } from '@aic-kits/remix/server';

export type FieldDef =
  | true
  | {
      date?: boolean;
      nullable?: boolean;
      default?: unknown;
      createOnly?: boolean;
      extract?: (value: unknown) => unknown;
    };

interface PrismaModelCallable {
  create: (args: unknown) => Promise<unknown>;
  update: (args: unknown) => Promise<unknown>;
  delete: (args: unknown) => Promise<unknown>;
}

interface CrudModelOptions {
  model: unknown; // a prisma.<model> delegate
  fields: Record<string, FieldDef>; // form key -> coercion rule
  include?: unknown;
  mapResponse: (row: unknown) => Record<string, unknown>;
  overrides?: Partial<PrismaModelDelegate>;
}

function extractField(value: unknown, def: FieldDef): unknown {
  if (def === true) return value as string;
  if (def.extract) return def.extract(value);
  if (def.date) return value && value !== '' ? new Date(value as string) : null;
  if (def.nullable) return (value as string) || null;
  if (def.default !== undefined) return (value as string) || def.default;
  return value as string;
}

export function createCrudModel(options: CrudModelOptions): PrismaModelDelegate {
  const { model: raw, fields, include, mapResponse, overrides } = options;
  const model = raw as PrismaModelCallable;

  const generated = {
    create: async (args: unknown) => {
      const { data } = args as { data: Record<string, unknown> };
      const createData: Record<string, unknown> = {};
      for (const [key, def] of Object.entries(fields)) {
        if (key in data) createData[key] = extractField(data[key], def);
      }
      return mapResponse(await model.create({ data: createData, ...(include && { include }) }));
    },
    update: async (args: unknown) => {
      const { where, data } = args as { where: { id: string }; data: Record<string, unknown> };
      const updateData: Record<string, unknown> = {};
      for (const [key, def] of Object.entries(fields)) {
        if (def !== true && def.createOnly) continue;
        if (key in data) updateData[key] = extractField(data[key], def);
      }
      return mapResponse(await model.update({ where, data: updateData, ...(include && { include }) }));
    },
    delete: async (args: unknown) => {
      const { where } = args as { where: { id: string } };
      // Let Prisma errors (e.g. P2003) propagate — the route handler maps them.
      return model.delete({ where });
    },
  } as PrismaModelDelegate;

  return { ...generated, ...overrides } as PrismaModelDelegate;
}
```

### `app/utils/handle-data.server.ts` — reusable (copied from opilot-pm)

Wraps `parseTableParams` (read query → params) + `mapTableResponse` (service result →
`{ data, total, pagination }`).

```ts
import { parseTableParams, mapTableResponse } from '@aic-kits/remix/server';
import type {
  TableParamsConfig,
  TableDataResponse,
  TableParams,
} from '@aic-kits/remix/server';

interface FetchHandler<T, P = TableParams> {
  fetch: (params: P) => Promise<{ data: T[]; total: number; page: number; pageSize: number }>;
  postProcess?: (result: { data: T[]; total: number; page: number; pageSize: number }) => Promise<typeof result>;
}

export async function handleData<T, P = TableParams>(
  request: Request,
  config: TableParamsConfig,
  handler: FetchHandler<T, P>,
  isMultiTable = false,
): Promise<TableDataResponse<T>> {
  const params = parseTableParams(new URL(request.url).searchParams, config, isMultiTable);
  let result = await handler.fetch(params as P);
  if (handler.postProcess) result = await handler.postProcess(result);
  return mapTableResponse(result) as TableDataResponse<T>;
}
```

### `app/config/company-table.server.ts` — the CRUD config (writes)

```ts
import type { CrudActionConfig } from '@aic-kits/remix/server';
import type { PrismaClient } from '@prisma/client';
import { createCrudModel } from '~/utils/crud-model.server';

export function getCompanyCrudConfig(
  prisma: PrismaClient,
): Record<string, CrudActionConfig> {
  return {
    companies: {
      model: createCrudModel({
        model: prisma.company,
        fields: {
          name: true,
          taxCode: { nullable: true },
          address: { nullable: true },
          phone: { nullable: true },
          bankAccount: { nullable: true },
        },
        include: { _count: { select: { buyerContracts: true, sellerContracts: true } } },
        mapResponse: (r) => {
          const row = r as {
            id: string; name: string; taxCode: string | null; address: string | null;
            phone: string | null; bankAccount: string | null;
            _count: { buyerContracts: number; sellerContracts: number };
            createdAt: Date; updatedAt: Date;
          };
          return {
            id: row.id, name: row.name, taxCode: row.taxCode, address: row.address,
            phone: row.phone, bankAccount: row.bankAccount,
            contractCount: row._count.buyerContracts + row._count.sellerContracts,
            createdAt: row.createdAt, updatedAt: row.updatedAt,
          };
        },
        // FK RESTRICT (P2003) and duplicate taxCode (P2002) are mapped to a 400 /
        // 409 by handleCrudRouteAction — no custom error handling here (Decision 3).
      }),
      requiredFields: ['name'],
    },
  };
}
```

### `app/routes/companies.tsx` — the page

```tsx
import { Box, Table } from '@aic-kits/react';
import type { Column, RecordWithId } from '@aic-kits/react';
import { useCrudTable } from '@aic-kits/remix';
import { handleCrudRouteAction } from '@aic-kits/remix/server';
import type { ActionFunctionArgs, LoaderFunctionArgs } from '@remix-run/node';
import { json } from '@remix-run/node';
import { useLoaderData } from '@remix-run/react';

import { buildCompanyColumns } from '~/components/company/columns';
import { COMPANY_TABLE } from '~/config/company-table';
import { getCompanyCrudConfig } from '~/config/company-table.server';
import { prisma } from '~/lib/prisma';
import type { CompanyRow } from '~/models/company.model';
import { CompanyService } from '~/services/company.service';
import { handleData } from '~/utils/handle-data.server';

interface LoaderData {
  companies: {
    data: CompanyRow[];
    total: number;
    pagination: { page: number; pageSize: number; total: number };
  };
}

export const loader = async ({ request }: LoaderFunctionArgs) => {
  const companies = await handleData(request, COMPANY_TABLE, {
    fetch: (params) => CompanyService.getAll(params as never),
  });
  return json<LoaderData>({ companies: companies as unknown as LoaderData['companies'] });
};

export async function action({ request }: ActionFunctionArgs) {
  return handleCrudRouteAction(request, getCompanyCrudConfig(prisma));
}

export default function CompaniesPage() {
  const { companies } = useLoaderData<LoaderData>();

  // Drop pagination/options/onAction; spread the rest straight into <Table>.
  const { pagination: _p, options: _o, onAction: _a, ...tableProps } = useCrudTable<RecordWithId>({
    config: COMPANY_TABLE,
    loaderData: companies,
    buildColumns: () => buildCompanyColumns(COMPANY_TABLE.requiredFields) as Column<RecordWithId>[],
  });

  return (
    <Box maxWidth="1200px" width="100%" style={{ margin: '0 auto' }} paddingY="md">
      <Table {...tableProps} title="Công ty" noDataMessage="Chưa có công ty nào" />
    </Box>
  );
}
```

### How a request flows

```
Browser ── GET /companies?page=1&search=acme ─────────────────────────────────┐
  companies loader        → handleData(req, COMPANY_TABLE, { fetch: getAll })  │
                              → parseTableParams → CompanyService.getAll       │ read
                              → mapTableResponse → json({ companies })         │
  CompaniesPage           → useCrudTable({ config, loaderData, buildColumns }) │ render
                              → <Table {...tableProps} />                      │

Browser ── POST /companies  (intent=create|update|delete, table=companies) ───┐
  companies action        → handleCrudRouteAction(req, getCompanyCrudConfig)  │ write
                              → createCrudModel.create/update/delete           │
                              → Prisma → reload loader                         │
```
